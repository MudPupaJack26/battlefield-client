## 🧩 About

**Battlefield Companion** is a curated list of Battlefield open-source tools:

- **Overlays** — on-screen helpers, layout notes, minimap reference, spawn overview
- **Quality-of-Life Helpers** — loadout catalog, class notes, overlay reference
- **Research Notes** — map layouts and config notes for educational use

Based on publicly available community tools and overlay helpers.

---

## ✨ Features

### ESP
- Spawn Overview — review spawn points in practice sessions
- Hitbox Notes — visualize collision zones for study
- Replay Notes — record and review match runs
- Playback Speed — adjust study playback (0.1x to 5x)

### Wallhack
- Loadout Catalog — browse weapons, attachments, gadgets
- Custom Kit Notes — organize class presets
- Scope Visibility — improved optics clarity notes

### Aimbot
- Practice Mode Notes — segment study on any map
- Vehicle Control Notes — reference vehicle handling mid-match
- Trajectory Notes — chain complex maneuvers in the sandbox
